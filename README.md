## 快速开始

1. 首次使用先安装 **BepInEx 6 Unity IL2CPP Windows x64**，本机验证版本 `6.0.0-be.785`，下载步骤见安装教程。
2. 下载 Release 附件 `LongYinTrainer-0.4.30.5.zip`，将其中的 `BepInEx` 文件夹合并到游戏根目录，与 `LongYinLiZhiZhuan.exe` 同级。GitHub 的 **Source code** 压缩包是源码，不是安装包。
3. 启动游戏并读取存档，点击游戏窗口，按 **H** 打开“江湖札记”。
4. 选择上方页签，开关类点击启用，数值类填写后点击对应的“应用”按钮。
5. 查看底部状态提示确认结果，再按 **H** 收起面板继续游戏。

发布 ZIP 是完整的 **Mod 插件包**，包含插件和安装、使用说明，**不含 BepInEx 加载器**。玩家不需要编译、安装 .NET SDK，也不需要旧图片或游戏解包数据。

## 常用操作

- **添加物品：** H → 背包物品 → 搜索或分类 → 点选物品 → 填数量等参数 → 添加到主角背包。这里是生成目录，不是背包已有物品列表。
- **编辑已有装备：** 先在游戏原生背包点击目标装备，再进入“物品修改”核对并修改。
- **锁定势力资源：** 核对势力名称 / ID → 输入数值 → 应用势力数值 → 锁定当前资源。目标来自所选角色的势力，未选角色时回退到主角。锁定后不随角色选择转移，资源增加和消耗都会恢复到锁定值；换存档 / 势力实例变化或重启后解除。
- **全地图视野：** 在“更多功能”开启“主角全地图视野”。交互仍需接近目标，关闭不会撤销已经发现的事件。

修改前请备份存档。关闭功能或卸载插件不会自动撤销已写入存档的数值、物品和发现记录。更多步骤见 [使用说明](docs/USAGE.md)。

## 从源码构建

准备 Windows、可构建 net6.0 的 .NET SDK，以及已安装 BepInEx IL2CPP 并成功运行过一次的游戏：

```powershell
.\scripts\Build.ps1 -GamePath 'D:\你的游戏目录\LongYinLiZhiZhuan'
.\scripts\Package.ps1 -GamePath 'D:\你的游戏目录\LongYinLiZhiZhuan'
```

仓库只收录源码、文档、脚本和模拟测试；游戏程序集仅作为本机编译引用，不随仓库或发布包分发。完整步骤见 [构建教程](docs/BUILD.md)。
