# 角色编辑（0.4.31.28 测试版）

按 H 打开修改器，进入“角色数值”。顶部姓名与 ID 是实际修改对象。修改 NPC 前，打开其原版详情并点击“选择当前查看角色”，或按姓名／ID 选择。

- **外观代码**：复制当前角色代码，或粘贴新建角色界面导出的形象代码并应用。主角、NPC 共用原生代码。代码包含性别、五官及肤色，服装由装备决定。使用固定立绘的 NPC 会切换到原版可编辑形象显示。
- **六维、武学、技艺**：点击对应“展开编辑”，逐项修改基础值和上限。两列分别支持批量填入、单独应用，也能同时应用。只应用其中一列时不写入另一列；不自动将基础值压到上限。
- **专长与喜好**：勾选添加，取消勾选移除；支持多选及喜好翻页，点击应用写入当前角色。返回放弃未应用输入。

应用后使用游戏自身保存功能保留修改。错误数值不会部分写入；错误外观代码恢复原外观。

## 安装器重复文件处理

固定位置 `BepInEx/plugins/LongYinTrainer.dll` 会覆盖更新。子目录同名副本，以及文件名不同但程序集名为 `LongYinTrainer` 的副本，会在写入前拦截并列出路径。请把冲突文件移出整个 `plugins` 目录后重试。安装器不会擅自删除其他插件或用户配置。
