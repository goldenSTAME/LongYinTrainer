# 旧自创功法功能迁入官方窗口

目标：官方窗口是唯一编辑主体，不恢复旧的大面板。已有图标、效果列表、范围及架势预览保留；只补官方缺失的编辑能力。

## 0.4.31.3 的改动

- 当前 MOD 草稿的特效添加按钮始终可点，不再受品级对应的数量上限禁用。
- 点击直接调用官方 GetAvailableSpeAddList 和 RefreshChooseSpeAddDataUI，跳过数量检查；实际添加、重复筛选、效果行编辑和移除仍由原版处理。
- 文案为“新增特效（已有 N）”，不伪造计数，不修改 SpeAddNumMax 全局数组。
- 原版候选池耗尽时明确提示，不把“没有候选”当成数量上限。
- 作用域仍是本次 MOD 直接打开的草稿；常规创建流程不受影响。

| --- | --- | --- |
| 名称、描述 | 原生输入框及名称检查 | 直接保留；已沿用 |
| 原版图标 | 图标显示与随机切换 | 保留显示，补按分类选择；尚未新增选择器 |
| 类别、品级 | 原流程在编辑前选定 | 在官方窗口内补选择控件，换类别时重建兼容草稿并保留各类别草稿；优先迁移 |
| 基础伤害、伤害加成 | 原生加减控件 | 保留控件和说明，补直接输入；单项上限需分别检查，不能认为预算解锁就全部无限 |
| 内力消耗 | 自动计算和显示 | 补手动覆盖/恢复自动，保证刷新和确认不覆盖手动值 |
| 经验倍率、使用次数、势力、目标、结算顺序、位移 | 草稿数据中存在字段，窗口未完整暴露 | 官方窗口内增加紧凑的高级参数区域；校验枚举、数值及类别适用性 |
| 升级/装备/使用效果 | 原生主要编辑当前类别对应的目标效果表 | 保留原生效果行，增加三表切换；切换绑定目标表，不能混写；优先迁移 |
| 特效数量 | 原生按品级限制 | 0.4.31.3 已编码解除；超过原上限的实际添加与保存尚待验证 |
| 学习条件 | 有原生数据，无完整创建控件 | 在高级参数区域补逐项编辑 |

| 进攻/防御架势 | 原生选择器和说明 | 沿用说明，补逐部位输入 |
| 动作、武器、弹道、视觉特效、拖尾 | 数据有字段，窗口缺少选择 | 在同一官方窗口加入演出选项，候选来自兼容的原版模板；可变子对象深复制 |
| 外部图片导入与重新加载 | 原生图标使用资源名称 | 保留 MOD 图片存储与资源解析，按官方新功法 ID 关联；验证跨启动重载后再启用 |
| 自定义冷却 | 不对应 KungfuSkillData 独立字段 | 仍需 MOD 附加元数据，绑定官方 ID；保持默认走原生冷却 |
| 编辑原版、已学功法 | 官方当前是创建新功法 | 需独立的编辑模式和引用定位，避免点确认再次创建重复功法 |
| 保存、学习、生成秘籍 | 官方确认后已原生登记/学习/给书 | 继续复用官方流程，验证旧档另存重载；避免 MOD 再发一次奖励 |
| 旧 MOD 功法载入/删除/恢复 | 旧 ID 和配置不是官方新存储 | 先做适配层，保留原 ID，不批量迁移；删除仍需兼容占位 |
| 战斗试用 | 官方窗口无该入口 | 最后迁移，需验证场景切换、技能栏还原和未保存草稿保留 |

## 0.4.31.4：五项自定义的第一版

主窗口继续使用原版；子编辑器复用官方 chooseUI、按钮模板、名称输入框模板。不创建额外 Canvas。模板按钮清除原监听，统一在主线程轮询点击，避免 managed UnityAction 的 IL2CPP 委托生命周期问题（该设计不等于已证明旧卡死原因）。

- 效果/加成行加减按钮进入数值输入；百分比效果按 50=50% 输入。
- 基础伤害行进入伤害、手动内力消耗输入；后续刷新与确认保持手动内力值。
- 选择范围：释放范围支持最多八层，格式 类型,最小,最大，各层分号分隔；作用范围单组。半径限制 32，避免预览生成过多格子。

- 骰子：选择原版图标，按原版功法名称分页；暂不支持外部图片导入。
- 效果每页五项，PgUp/PgDn 翻页；有有效 RectTransform 的效果区也支持鼠标滚轮。

尚未实机验证控件尺寸、点击、分页、输入框焦点、取消以及保存重载。编译和旧逻辑回归不能替代这些验证。
