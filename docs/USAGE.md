# 龙胤立志传 修改器使用说明

> **这是较为暴力的修改，会明显破坏数值平衡，影响战斗、养成和探索体验。建议先体验原版，修改前备份存档，按需开启功能。关闭功能不会自动撤销已经写入存档的修改。**

## 打开面板

安装见 [INSTALL.md](INSTALL.md)。进入存档、让游戏窗口获得焦点后，按 **H** 打开“江湖札记”，再次按 H 收起。

**H 不是全部功能的总开关。** 各项功能需单独开启；填写数字后点击对应的“应用”按钮。收起面板后持续效果仍生效，底部状态栏显示操作结果。

修改快捷键：退出游戏，在 `BepInEx/config/codex.longyin.trainer.cfg` 的 `[General]` 下修改 `TogglePanelKey`（默认 `H`），保存并重启。按 H 无反应时先检查游戏焦点及 BepInEx 日志是否加载 `LongYin Trainer 0.4.27`。

## 角色、物品与装备

“角色数值”可选择主角、当前查看角色或按姓名 / ID 查找。修改前核对目标，填写后应用；要改主角时先点击“选择主角”。

“背包物品”：搜索或选择分类 → 点击物品卡片 → 填数量及适用的等级 / 稀有度 → 点击“添加到主角背包”。目录不是已有背包物品。首次加载等待提示完成；资源加载后可以点击“刷新数据”。

“物品修改”：先在游戏原生背包点击目标装备，再打开该页，核对装备后写入、删除或清空词条。坐骑等物品按页面实际字段编辑。

## 势力资源锁定

1. 打开“势力 / 开局”，核对势力名称和 ID。目标来自当前所选角色的势力，未选角色时回退到主角。
2. 输入资源并点击“应用势力数值”。
3. 点击“锁定当前资源”，锁定当前实际金钱与全部资源值。
4. 恢复正常消耗时点击“解除资源锁定”。调整锁定数值时先解除，再应用并重新锁定。

收起面板仍生效；锁定不会随角色选择自动转移，增加和消耗都会恢复到锁定值。换存档、世界 / 势力实例变化或重启后需重新锁定。

## 全地图视野

在“更多功能”开启“主角全地图视野”，通过原生机制发现事件并显示稀有度。交互仍需接近目标。关闭可恢复视野范围，但不会撤销已经记录的发现状态。

## 突破自选

1. 在游戏功法界面点击“突破”，停留在突破准备页。
2. 按 H 打开“突破自选”；未读到功法时重新点击页签刷新。
3. 从候选池选择效果，确认已锁定后收起面板，继续原版突破流程。
4. 在三张卡中选择卡牌，最终数值继承所选卡牌稀有度。锁定效果种类不等于直接变成红卡。

选择仅对下一次突破生效，可点击“取消锁定”。原版伤势代价和结算保留。当前版本不修改卡面文字，以状态栏和日志中的最终数值为准。

## 自创功法

进入藏经阁 / 书房，在建筑操作中点击“自创功法”，基于现有功法编辑参数、范围、姿态、动作、弹道与特效，完成后点击“保存”。

定义保存在 `BepInEx/config/LongYinTrainer.custom-kungfu.json`，游戏存档只保存自创功法 ID。备份或迁移时同时保留此文件及自己使用的自定义图标。

## 其他设置

### 手动生成大地图奇遇（0.4.30.5）

在大地图行走状态按 H → **奇遇生成**，先选择品质（支持橙色、红色），再选择“随机类型”或在分页列表中点选奇遇类型，点击“在主角身边生成一个”。收起面板后点击新出现的奇遇图标前往，按原版流程触发。

每次只新增一个独立奇遇，不会重抽或清空已有事件。包含普通大地图奇遇，以及原版明确设在大地图上的世界奇遇：异草奇花、仙木灵果、失落宝藏、神兵现世、失传秘籍、千里名驹、武学奇才、世外高人、皇家宝库、神秘石碑、中元鬼市。世界奇遇在列表中标为“江湖传闻”，生成后同步登记原版传闻列表。

手动生成不受原版出现日期限制，不会更改游戏日期或原版自动出现记录。保留原版有效期（当前上述十种探索奇遇为 20 天，中元鬼市为 30 天）。拍卖、比赛、节日及掌门大会等原版城镇／门派内部事件不纳入列表，也不纳入任务专属事件。品质同时决定事件难度，奖励仍按原版脚本结算。生成事件随正常游戏存档保存；城市内、战斗中或未载入存档时不能生成。

### 其他门派兑换功绩

按 H → 势力 / 开局 → 右下方“其他门派 · 兑换功绩”。用“上个 / 下个”选择门派，输入数值后点击“应用功绩”。也可先打开游戏中的门派兑换界面，再点“读取当前兑换门派”。每个门派的功绩独立保存，只修改当前选中的门派，不受角色页的目标角色影响。

切换门派会重新读取其功绩，未应用的输入不会保留。“重读数值”可刷新兑换消费后的余额。允许输入 0–100000000 的有限数字；应用后请正常保存游戏。该字段是兑换界面的“功绩”，与角色页的“势力贡献”不同。

打造 / 炼丹的价值、品质和天数填写后应用；更多功能中的倍率点击“应用扩展设置”。“下次启动跳过片头”下次启动生效；开局相关功能用于新建角色。

修改前备份存档。关闭开关或卸载不能自动回滚已加入的物品、角色数值和发现记录。卸载及日志位置见 [安装说明](INSTALL.md)。

## 0.4.27 物品修改
在游戏背包点击物品，再打开物品修改页。物品数值支持名称、价值、等级、稀有度（0–5）、重量和毒量，药品、食物和材料也可编辑。装备及坐骑可通过底部按钮切换到原有词条／属性编辑。更改等级或稀有度不会重抽词条。



## 城市与自创功法更新（0.4.29.5）
城市属性支持逐城编辑与锁定，见 CITY-EDITOR.md。仇敌助战与逐人处置见 BUILDING-COMBAT.md。本地图标支持 PNG/JPG，导入后保存功法；预览失败时界面显示阶段与原因，完整诊断位于 BepInEx/LogOutput.log，可点击重新加载已存图标。最新图标显示仍需实机复测。
# 0.4.30 功法修改

藏经阁／书房 → 自创功法 → **载入原版功法编辑**，选择目标功法后编辑并保存。内功、轻功、绝技和六类攻击功法均可修改，保存后刷新已习得角色的效果与总加成。自创功法仍可在保存／管理页重新载入。

内功、轻功、绝技请装入各自的原生槽位。原版修改会影响所有使用该功法的角色；更换类别前须卸下。升级效果在后续升级时获得。详见 [功法编辑说明](KUNGFU-EDITING.md)。

## 战斗技能栏刷新优化（0.4.30.8）

同一角色首次显示时由原生方法绑定技能栏，后续回合复用已有绑定，避免重复将技能图标设为未初始化并再次写入名称、图片。仅在原生绑定事件发生时核对角色、界面及技能槽，不增加逐帧检查。切换角色、替换技能实例或技能 ID、改变攻击栏顺序及数量、重新创建界面或修改自创图标配置时重新绑定。战斗开始和结束清理绑定记录。

冷却、蓄力、可用状态、Buff、快捷键、点击及界面显隐完全交给原版的正常更新流程。复用分支只跳过重复初始化，不追加调用状态、Buff 或自动战斗设置刷新，也不写入界面状态，不改变原生刷新计时。没有活动角色时保留游戏原有的界面隐藏行为。

移除模组在原生更新后逐帧追加的名称、图片覆盖，以及相关子物体查找和覆盖层维护。自创名称通过功法定义提供，自定义图片通过原生图集资源加载入口提供，再由游戏界面显示。技能结算、AI、快捷键与点击保持原生逻辑。

这是供实机对比的版本，重点观察连续释放技能时的卡顿及自创图标显示。没有新增性能开关。编译和模拟回归检查不能代替实际战斗测试；尚未确认性能改善幅度。

## 0.4.30.9：功法状态词条编辑（第一步）

在“自创功法 → 修炼／效果 → 逐条自选”中，九类功法均可按“自身状态、对方状态、攻触发、守触发”筛选。选中词条后，下方显示原生持续及叠层规则，左下方显示当前效果表的原版配置示例，优先展示同类别。示例来自未修改的原版来源，并非实战有效性保证。

数值仍按原有百分比／数值单位保存；持续参数和叠层规则仅作说明，不修改共享 Buff 定义。内功、轻功、绝技的使用效果与攻击技能的通用合并路径不同，界面会提示对照原版配置。此版没有新增战斗计时、状态覆盖或技能栏刷新。

## 0.4.30.10：九类功法分别编辑

先在基本参数选择内功、轻功、绝技、拳掌、剑法、刀法、长兵、奇门或射术，再选择该类总母版。所有来源选择器（包括原版编辑、动作、图标等）只列出当前类别，确认时再次校验类别。

威力加成、修炼需求、升级、装备和使用效果的新增目录，分别取当前类别原版对应表中的非零配置；“全部”指本类别本效果表的全部词条。没有原版样本的词条暂不提供新增，这并不代表原版必然不支持。现有配置中的旧词条仍可编辑或删除，不会被目录过滤自动清除。

切换类别首次采用该类原版模板，各类草稿在本次编辑期间分别暂存，切回可恢复；名称、描述与功法 ID 跟随当前编辑对象。保存只保存当前类别。载入其他功法、新建或保存后开始新的编辑周期，不承诺保留其他类别的未保存草稿。类别切换仍受原有已装备功法的保存校验约束。

此次只调整编辑器，未添加战斗计时、状态重算或技能栏刷新。

## 0.4.30.11：三类专属效果的原生数据验证

修复原版功法编辑入口：先建立目标类别草稿，再复制模板，避免轻功、绝技等被同类模板校验拦截。

保存内功、轻功、绝技前，序列化后的定义会通过独立原生等级实例验证：1 级和 10 级装备／使用缓存、原生充能与激活参数、激活时装备加成翻倍及到期恢复。验证失败时不覆盖配置。临时实例不加入角色技能栏、不写入玩家存档；战斗仍走原生方法，没有新增战斗刷新。

2026-10-25 已在本机游戏运行时验证 441 个原版模板（内功 153、轻功 136、绝技 152）：将原有升级／装备／使用词条调整至 1.25 倍，经配置序列化重新读取后验证上述原生流程，441 通过、0 失败。另有 43 项模拟回归检查通过，包括九类原版编辑入口。此项是独立实例的原生链路验证，不是所有功法实际施放、命中、受击及特殊 Buff 的完整实战测试。

诊断仅在明确放置 LongYinTrainer.utility-audit.request 文件后，下次原生数据库加载完成时运行一次；平时不轮询。报告为 BepInEx/config/LongYinTrainer.utility-audit.txt。

## 0.4.30.12：词条目录空分类修正

逐条编辑默认打开本类别、本效果表的“全部”。不显示没有词条的分类；“常用”与“全部”内容完全相同时也不再重复显示。分类失效时自动回到“全部”，按钮和词条随实际分类数量排布。若当前效果表确实没有原版词条，则显示明确说明，已有词条仍可编辑和删除。此次仅调整编辑器目录，不改保存格式和战斗计算。

## 0.4.30.13：移除常用分类

词条目录彻底移除“常用”入口，默认显示“全部”，其余分类继续隐藏空项。

## 0.4.30.14：日期冻结解除

日期冻结改为按需安装拦截。关闭时移除 ChangeDay 两个入口的冻结补丁；未开启时不安装冻结补丁。界面读取实际运行状态，开关变化输出明确日志，配置变更也同步处理；补丁更新失败时停止拦截。不会补算天数、写回日期或强制解除游戏本身的暂停。

使用真实 Harmony 与模拟 GameController 的 64 项检查通过，覆盖 30 轮反复开关、两个换日入口、外部配置修改与重复关闭。尚未在用户发生停滞的存档中复现，不能将“原先永久注册的条件补丁”认定为已证实的根因。

## 0.4.31.28 角色编辑
角色数值页新增外观代码、专长与喜好；六维、武学、技艺可展开逐项分别设置基础值和上限。主角与所选 NPC 共用。应用后请保存游戏。
