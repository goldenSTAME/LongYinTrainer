# 龙胤立志传 修改器使用说明

> **这是较为暴力的修改，会明显破坏数值平衡，影响战斗、养成和探索体验。建议先体验原版，修改前备份存档，按需开启功能。关闭功能不会自动撤销已经写入存档的修改。**

## 打开面板

安装见 [INSTALL.md](INSTALL.md)。进入存档、让游戏窗口获得焦点后，按 **H** 打开“江湖札记”，再次按 H 收起。

**H 不是全部功能的总开关。** 各项功能需单独开启；填写数字后点击对应的“应用”按钮。收起面板后持续效果仍生效，底部状态栏显示操作结果。

修改快捷键：退出游戏，在 `BepInEx/config/codex.longyin.trainer.cfg` 的 `[General]` 下修改 `TogglePanelKey`（默认 `H`），保存并重启。按 H 无反应时先检查游戏焦点及 BepInEx 日志是否加载 `LongYin Trainer 0.4.27`。

## 角色、物品与装备

“角色数值”可选择主角、当前查看角色或按姓名 / ID 查找。修改前核对目标，填写后应用；要改主角时先点击“选择主角”。

“背包物品”：搜索或选择分类 → 点击物品卡片 → 填数量及适用的等级 / 稀有度 → 点击“添加到主角背包”。目录不是已有背包物品。首次加载等待提示完成；资源加载后可以点击“刷新数据”。

“物品修改”：先在游戏原生背包点击目标装备，再打开该页，核对装备后写入、删除或清空词条。坐骑等物品按页面实际字段编辑。

## 势力资源锁定

1. 打开“势力 / 开局”，核对势力名称和 ID。目标来自当前所选角色的势力，未选角色时回退到主角。
2. 输入资源并点击“应用势力数值”。
3. 点击“锁定当前资源”，锁定当前实际金钱与全部资源值。
4. 恢复正常消耗时点击“解除资源锁定”。调整锁定数值时先解除，再应用并重新锁定。

收起面板仍生效；锁定不会随角色选择自动转移，增加和消耗都会恢复到锁定值。换存档、世界 / 势力实例变化或重启后需重新锁定。

## 全地图视野

在“更多功能”开启“主角全地图视野”，通过原生机制发现事件并显示稀有度。交互仍需接近目标。关闭可恢复视野范围，但不会撤销已经记录的发现状态。

## 突破自选

1. 在游戏功法界面点击“突破”，停留在突破准备页。
2. 按 H 打开“突破自选”；未读到功法时重新点击页签刷新。
3. 从候选池选择效果，确认已锁定后收起面板，继续原版突破流程。
4. 在三张卡中选择卡牌，最终数值继承所选卡牌稀有度。锁定效果种类不等于直接变成红卡。

选择仅对下一次突破生效，可点击“取消锁定”。原版伤势代价和结算保留。当前版本不修改卡面文字，以状态栏和日志中的最终数值为准。

## 自创功法

进入藏经阁 / 书房，在建筑操作中点击“自创功法”，基于现有功法编辑参数、范围、姿态、动作、弹道与特效，完成后点击“保存”。

定义保存在 `BepInEx/config/LongYinTrainer.custom-kungfu.json`，游戏存档只保存自创功法 ID。备份或迁移时同时保留此文件及自己使用的自定义图标。

## 其他设置

### 其他门派兑换功绩

按 H → 势力 / 开局 → 右下方“其他门派 · 兑换功绩”。用“上个 / 下个”选择门派，输入数值后点击“应用功绩”。也可先打开游戏中的门派兑换界面，再点“读取当前兑换门派”。每个门派的功绩独立保存，只修改当前选中的门派，不受角色页的目标角色影响。

切换门派会重新读取其功绩，未应用的输入不会保留。“重读数值”可刷新兑换消费后的余额。允许输入 0–100000000 的有限数字；应用后请正常保存游戏。该字段是兑换界面的“功绩”，与角色页的“势力贡献”不同。

打造 / 炼丹的价值、品质和天数填写后应用；更多功能中的倍率点击“应用扩展设置”。“下次启动跳过片头”下次启动生效；开局相关功能用于新建角色。

修改前备份存档。关闭开关或卸载不能自动回滚已加入的物品、角色数值和发现记录。卸载及日志位置见 [安装说明](INSTALL.md)。

## 0.4.27 物品修改
在游戏背包点击物品，再打开物品修改页。物品数值支持名称、价值、等级、稀有度（0–5）、重量和毒量，药品、食物和材料也可编辑。装备及坐骑可通过底部按钮切换到原有词条／属性编辑。更改等级或稀有度不会重抽词条。



## 城市与自创功法更新（0.4.29.5）
城市属性支持逐城编辑与锁定，见 CITY-EDITOR.md。仇敌助战与逐人处置见 BUILDING-COMBAT.md。本地图标支持 PNG/JPG，导入后保存功法；预览失败时界面显示阶段与原因，完整诊断位于 BepInEx/LogOutput.log，可点击重新加载已存图标。最新图标显示仍需实机复测。
