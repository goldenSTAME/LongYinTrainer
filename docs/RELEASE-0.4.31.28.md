# 0.4.31.28 角色编辑与覆盖安装检查

适配《龙胤立志传》1.1.3f0，Windows x64。

## 新增功能

进入存档按 **H → 角色数值**，核对顶部目标姓名与 ID。

1. **外观代码**：导入、导出新建角色界面的原生形象代码，主角和 NPC 共用；错误代码恢复原外观。固定立绘 NPC 导入时切换到原版可编辑形象。
2. **六维／武学／技艺 → 展开编辑**：基础值与上限分列逐项编辑，可批量填入并分别应用，不再捆绑设置。
3. **专长与喜好**：多选添加、取消勾选移除，喜好分页保留选择。修改 NPC 前先打开其原版详情并点击“选择当前查看角色”，也可按姓名／ID 选择。

应用后通过游戏保存保留修改。外观代码包括性别、五官和肤色；服装仍由装备决定。

## 安装更新

退出游戏，把 EXE 放在游戏根目录（与 LongYinLiZhiZhuan.exe 同级）运行。

- 固定路径的 LongYinTrainer.dll 覆盖更新，不生成第二份 DLL。
- 子目录同名旧插件，以及改名但程序集身份相同的副本，会在写入前拦截并列出路径。将冲突副本移出整个 plugins 目录再重试。
- 保留用户配置和自创功法定义／图标，继续内置并校验 BepInEx 785。无需安装开发用 SDK。
- 不要为了更新删除整个 config；首次启动生成接口仍可能联网。
