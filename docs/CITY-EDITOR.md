# 城市属性（本机版 0.4.29.1）

性能修正：用户反馈开启城市锁定后走地图、挂机卡顿，解除后恢复。原实现每帧遍历锁定城市并分配临时列表；现改为每 0.5 秒兜底检查一次，无失效城市时不创建临时列表。原版属性变更函数仍即时恢复锁定；直接写字段最多等待半秒。未锁定时跳过补丁中的世界读取。新增 7 项性能与时序回归检查，实际帧时间改善仍需游戏内复测。

H → 城市属性。按名称或 ID 查找，用“上一个／下一个”选择，也可先进入城市再点“读取当前场景”。

可编辑：治安、民心、城防（0–100），当前人口和人口上限（最大 10 亿，上限至少 1，当前人口不能大于上限）。

- **应用数值**：将五项输入一起写入当前所选城市。修改值按游戏原版存档流程保存。
- **应用并锁定本城**：写入并持续保持这座城市的五项数值。多座城市可以同时锁定，每城各自保存自己的目标值。
- **解除本城锁定**：只解除当前所选城市，其余城市保持锁定；不会恢复修改前数值。
- **重读当前数值**：丢弃本页未应用输入，重新读取所选城市。

切换城市前请先应用。编辑已锁定城市时，“应用数值”会一起更新它的锁定目标。关面板不会解除锁定；读档、换存档、重启后解除，需要重新开启。不同存档不会因城市 ID 相同而互相套用锁定。

本页编辑上方四项状态及人口上限。绿色月变化、下方资源产出、特产名称仍由原版计算，未在此版中修改。

验证：生产文件与 12 项模拟检查通过。测试覆盖多城独立、变更后恢复、更新锁定值、解除单城、无效输入拒绝、同 ID 换实例与换存档解除。未用模拟检查代替实际游戏 UI、过月或原生 Harmony 拦截验证。

测试命令：`dotnet run --project CityRegression/CityRegression.csproj -c Release`。
