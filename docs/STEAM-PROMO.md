[b]体验提醒：这是较为暴力的修改，会明显破坏游戏数值平衡，降低战斗难度，改变养成与探索节奏，影响原本的游戏体验。建议先体验原版，使用前备份存档，按需开启功能。下方截图均为修改后的展示效果，不代表原版或默认开启效果。[/b]

[h1]主要功能[/h1]
[list]
[*]战斗辅助：生命、内力、气力、伤势、技能充能和冷却等。
[*]角色数值：选择角色，调整属性、战斗和生活技能及上限。
[*]物品添加：分类搜索，设置数量及适用的等级、稀有度。
[*]装备词条：编辑基础和额外词条及适用装备、坐骑数值。
[*]打造、炼丹、烹饪：价值、品质和制作天数设置。
[*]势力资源：应用数值后可锁定，支持解除。
[*]主角全地图视野：使用游戏原生事件样式和稀有度显示。
[*]功法突破自选、自创功法，以及开局、经验和坐骑倍率设置。
[/list]

[h1]安装与使用[/h1]
1. 先退出游戏。首次安装需 BepInEx 6 Unity IL2CPP Windows x64；GitHub 安装教程提供已验证 build #785 的下载与完整安装步骤。
2. 将插件包内 BepInEx 文件夹合并到游戏根目录，与 LongYinLiZhiZhuan.exe 同级。
3. 启动并读取存档，按 [b]H[/b] 打开 / 收起“江湖札记”。H 只开关面板，功能需要单独开启；数字修改后点击对应“应用”。
4. 发布包包含 INSTALL.md 和 USAGE.md，首次使用请先阅读。插件包不包含 BepInEx 加载器。

[h1]使用前了解[/h1]
修改前备份存档。关闭面板不会关闭持续效果；卸载不会自动撤销存档中的修改。
资源锁定绑定点击时的势力，增加和消耗都会恢复到锁定值，换存档或重启后解除。全地图视野不扩大交互距离，关闭不会撤销已经发现的事件。
